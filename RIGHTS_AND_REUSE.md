# Rights and reuse

No open-source or open-data license is assigned in this release. The accompanying manuscript should be cited when it is available. The repository is https://github.com/KitePretty/breast-health-needs-and-support. No package DOI has been assigned.

The code and coded records are organized to allow inspection and reproduction of the reported statistical analyses. Do not describe this package as fully anonymous or free of all re-identification risk. Random research IDs replace platform identifiers; topic, rank, year, and coding combinations remain in the analysis data.

Public availability does not itself grant an open-source or open-data license. For reuse beyond inspection and reproduction, contact the study authors; any future reuse terms should follow institutional and data-source conditions. This document is not a signed institutional data use agreement. No third-party text or original Reddit identifier is distributed in this package.
