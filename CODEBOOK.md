# Coding definitions

Definitions accompanying the final coded analysis data. Binary codes use 1 for present and 0 for absent unless explicitly marked not applicable. Content codes can co-occur; C1 is a single pathway classification.

| Code | Name | Definition | Values |
|---|---|---|---|
| A1 | Diagnostic labeling | Post gives the bodily change an explicit disease label or links it to a specific condition. Code only explicit labels; do not infer. | 0/1 |
| A2 | Temporal information | Post describes symptom onset, duration, development, recurrence, or timing. Code only for symptom/bodily change timing — not appointment or result dates. | 0/1 |
| A5 | Emotional representation | Post expresses emotions generated by the symptom or health threat (fear, panic, anxiety, dread). Distinct from descriptions of functional impact. | 0/1 |
| B1 | Severity rule | Uses symptom severity, pain, hardness, texture, or physical quality to judge seriousness. | 0/1 |
| B3 | Duration rule | Uses symptom persistence, duration, or change over time to evaluate seriousness. | 0/1 |
| B4 | Age-illness rule | Uses age to interpret breast cancer risk or the need for care. | 0/1 |
| B7 | Stress-illness rule | Attributes symptoms to stress, lifestyle, hormonal changes, or other non-cancer explanations. | 0/1 |
| C1 | Interval position | Assigned to one of four intervals: Appraisal, Help-seeking, Diagnostic, or Pre-treatment. NA if not applicable. | 1/2/3/4/NA |
| C3 | Has human responses | At least one eligible first-level human, non-OP reply was recorded. A previously recorded eligible reply remains counted if its text later became unavailable. This variable must not be reconstructed solely from the retained comment rows. | 0/1 |
| D1 | Symptom interpretation seeking | Asks others to interpret the meaning or significance of a bodily change or a finding described in clinical-report language. | 0/1 |
| D2 | Risk assessment seeking | Asks explicitly whether the symptom is concerning or requires medical care. Code 1 only when OP explicitly asks; do not infer from anxious tone. NA if not applicable. | 0/1/NA |
| D3 | Emotional relief | The post explicitly seeks emotional relief, validation, reassurance, or an outlet for fear, anxiety, panic, or distress. Emotional expression alone does not qualify. | 0/1 |
| D4 | Experience sharing | Shares an update, timeline, result, or experience that may inform others. | 0/1 |
| D6 | Medical process information seeking | Asks about testing procedures, appointments, access to results, or subsequent steps in care. | 0/1 |
| E1 | Informational | Provides specific objective medical, procedural, or care-navigation information. General encouragement, vague reassurance, or personal experience alone do not qualify. | 0/1 |
| E2 | Emotional | Includes empathy, comfort, encouragement, validation, or “you are not alone” support. | 0/1 |
| E5 | Help-seeking encouragement | Explicitly encourages the user to see a medical professional. | 0/1 |
| E6 | Reassurance / normalization | Suggests the symptom is likely benign or not something to panic about. | 0/1 |
| E7 | Experiential information | Provides information through the commenter’s own comparable experience. | 0/1 |

C1 values: 1 = Appraisal; 2 = Help-seeking; 3 = Diagnostic work-up; 4 = Pre-treatment; blank = indeterminate/not applicable. The classifications describe the position represented at posting, not observed transitions in the same person.

For report-reading posts, D1 includes requests to understand the meaning or significance of findings in clinical-report language. D6 concerns procedures, appointments, result access, and next steps.

A support-category code records the presence of that content. It does not measure accuracy, usefulness, need satisfaction, or a clinical outcome.

## Core need–support mappings

| Need | Support category |
|---|---|
| D1 symptom interpretation | E1 informational |
| D2 risk assessment | E1 informational |
| D6 medical-process information | E1 informational |
| D3 emotional relief | E2 emotional |
| D2 risk assessment | E5 help-seeking encouragement |
